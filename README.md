# cpp-modules

**cpp-modules** is an open-source collection of reusable C++ libraries built with the **C++20 Modules** feature. It provides modern, modular, and reusable components that can be imported into C++ applications, reducing header dependencies, improving encapsulation, and enabling faster build times.

The library requires a **C++20-compliant compiler** with module support and is designed to be portable across Windows and Linux.
